## About the Project

**Araxia: Shadow of Etheros** is a retro RPG built under the classic **1.44 MB floppy disk** size constraint for the 2p Arcade Games contest.

---

## Getting Started / Controls

* **Move:** Arrow keys / WASD
* **Interact / Confirm:** Enter / Space
